# AI 聊天助手功能规格

## 核心功能

### 1. 对话功能
- 用户可以输入问题，AI 给出回答
- 支持多轮对话，AI 能记住之前的对话内容
- AI 回答要逐字显示，不要一次性全部出现（流式输出）

### 2. 消息记录
- 每发送一条消息，自动在右侧记录一条消息
- 显示消息预览（前30个字符）和发送时间
- 用户消息显示 👤，AI消息显示 🤖
- 点击右侧消息可以查看该消息的完整内容

### 3. 数据存储
- 对话历史保存在 LocalStorage 中
- 消息记录保存在 LocalStorage 中
- 刷新页面不会丢失对话记录

### 4. 界面功能
- 类似微信的聊天界面
- 用户消息在右边，AI 消息在左边
- 底部有输入框和发送按钮
- 可以清空对话，开始新的话题

### 5. Markdown 支持
- AI 的回答支持 Markdown 格式
- 支持代码高亮显示
- 使用 react-markdown 和 react-syntax-highlighter

## 技术要求

### API 调用
- 使用智谱 AI Chat Completions API
- 启用 stream 模式实现流式输出
- API Key 存储在环境变量中

### 错误处理
- 要处理 API 调用失败的情况
- 加载时要有明确的提示
- 输入框在发送时要禁用，避免重复发送

## 用户界面

### 聊天区域
- 显示所有消息记录
- 用户消息右对齐，AI消息左对齐
- 支持滚动查看历史消息

### 右侧消息记录面板
- 显示所有发送过的消息列表
- 每条消息显示预览和时间
- 点击可以查看消息详情

### 输入区域
- 文本输入框
- 发送按钮
- 消息计数显示
- 清空对话按钮
