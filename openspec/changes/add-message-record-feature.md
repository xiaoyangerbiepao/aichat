# 变更记录：添加右侧消息记录功能

## 变更 ID
`add-message-record-feature`

## 变更标题
添加右侧消息记录功能

## 变更类型
功能增强

## 变更描述
在聊天界面右侧添加消息记录面板，每发送一条消息自动记录，方便用户查看历史消息。

## 实现内容

### 1. 数据结构变更
- 从 `Conversation`（对话历史）改为 `MessageRecord`（单条消息记录）
- 每条记录包含消息内容、角色和时间戳

### 2. 功能变更
- **自动记录**：每发送一条消息（无论是用户还是AI），都会自动在右侧记录一条消息
- **显示格式**：显示消息预览（前30个字符）和发送时间
- **角色标识**：用户消息显示 👤，AI消息显示 🤖
- **点击查看**：点击右侧消息可以查看该消息的完整内容

### 3. 存储变更
- 从 `chat-conversations` 改为 `message-records`
- 每条消息独立存储，便于查看历史记录

### 4. 界面变更
- 右侧面板标题改为"消息记录"
- 按钮改为"清空记录"
- 移除了"新对话"按钮

## 技术实现

### 代码修改
- 修改 `App.tsx` 中的状态管理
